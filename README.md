# Personal Website

I'm Cheta Nzeogu and this is [my personal website](https://chetanzeogu.dev)

To build this, I used Svelte, with plain CSS, since Tailwind isn't really my thing.
I'm currently hosting on vercel.
## Setup

To run this, first clone the project and then run

```
npm i

npm run dev
```
You should be good to go afterwards :)
